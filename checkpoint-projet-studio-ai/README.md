# 📝 Application de Gestion de Tâches (Todo App)

## 📋 Spécification du Projet
Cette application web permet aux utilisateurs de gérer leurs tâches quotidiennes de manière simple et efficace. Elle a été conçue pour être légère, rapide et entièrement fonctionnelle sans dépendance externe.

### ✨ Fonctionnalités principales
- **Ajout de tâches** : Via un champ de saisie ou la touche Entrée.
- **Persistance des données** : Les tâches sont sauvegardées automatiquement dans le `localStorage` du navigateur.
- **Filtrage dynamique** : Affichez "Toutes", "À faire" ou "Terminées".
- **Suppression** : Suppression individuelle ou en masse des tâches terminées.
- **Design responsive** : Interface moderne et adaptative (mobile et desktop).
- **Sécurité** : Protection basique contre les failles XSS (échappement du HTML).

### 🛠️ Technologies utilisées
- **HTML5** (Structure sémantique, pas de "div soup")
- **CSS3** (Variables CSS, Flexbox, animations légères)
- **JavaScript (Vanilla)** (Manipulation du DOM, LocalStorage, événements)

## 🚀 Installation et Déploiement
1. Clonez ce dépôt ou téléchargez les fichiers.
2. Ouvrez `index.html` dans votre navigateur pour tester en local.
3. Pour le déploiement, ce projet est configuré pour être hébergé gratuitement via **GitHub Pages**.
